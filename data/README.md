# Policy PDFs go here

Put 5–10 public sample insurance policy PDFs in this folder (home, auto, renters, health).
Good places to look: insurers' "sample policy" pages and state insurance department websites
that publish approved policy forms.

Name files simply, e.g. `sample_home_policy.pdf`. The file name (without `.pdf`) becomes the
policy name in the app.

Use only public documents. Never use real customer data.
